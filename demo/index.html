This page exists to prove one thing: the chatbot can be dropped onto a site it knows nothing about without changing a single pixel of that site. Everything you see here is styled by this page's own CSS.

Deliberate collisions

This paragraph uses .message — the same class the widget's old stylesheet claimed globally. It must keep its cream background, italics and left rule.

This paragraph uses .hidden. The old stylesheet declared .hidden { display: none !important } globally, which would have made this line vanish. If you can read it, the scoping works.

A box with its own margins and padding. The old stylesheet's global * { margin: 0; padding: 0 } reset would have flattened this.

How a site embeds it

One tag, nothing else — no markup to paste, no stylesheet to link. Assets resolve against the script's own URL, so it works from any origin or CDN path.

Try the widget with book, contact, rooms, link or available to exercise each element type from the response contract. !xss, !unknown, !410, !403 and !429 drive the defensive paths.

This page opts into the mock transport (data-mock="true" below) — replies come from the local fixtures in nest-chatbot.js, not the API. Drop the attribute and add data-api-base + data-key to hit a real backend — the key must be a public-scoped ws_live_… key, and if the site has an origin allow-list configured, this page's origin must be registered on it first.
