How a site embeds it

One tag, nothing else — no markup to paste, no stylesheet to link. Assets resolve against the script's own URL, so it works from any origin or CDN path.

Try the widget with book, contact, rooms, link or available to exercise each element type from the response contract, and hostel, tenerife / canaria / ibiza, or pass / offer for the richer ones — quick replies, the property carousel and the promo card. rooms shows eleven options the way a real Las Palmas turn returns them — grouped into private rooms and beds, three per group with the rest behind Show 3 more, the party's total as the figure and the per-bed price under the name — and every booking button carries a 1.9.0 server-composed url with the stay in its query string, opened untouched. !xss, !unknown, !410, !403, !429 and !500 drive the defensive paths.
